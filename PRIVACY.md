# Privacy Policy

## Data Collection

This application processes resume data for analysis purposes.

## Data Protection

- All data is encrypted in transit (HTTPS)
- Uploaded files are processed securely
- Data is not shared with third parties
- Users can request data deletion

## Retention

- Uploaded resumes are retained for analysis
- User data is deleted upon request
- Logs are retained for 30 days

## Rights

- Users can access their data
- Users can request deletion
- Users can opt-out of analysis

For privacy questions: privacy@example.com
